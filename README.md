# Shopify App Store Loading Simulation

A static, front-end-only loading sequence inspired by the visual layout of the Shopify App Store. This is an independent simulation, not an official Shopify product and not connected to Shopify or GitHub.

## Sequence
1. White startup screen with a Shopify-inspired spinner.
2. Simulated asset loading list with GitHub source labels and GitHub mark.
3. Empty Shopify App Store-inspired shell with a loading indicator.
4. A final “Failed to connect with server” message.

All assets and loading events are simulated locally. No apps are fetched and no network requests are made.

## Run
Open `index.html` in a browser, or deploy the folder as a static site. No build step is required.
